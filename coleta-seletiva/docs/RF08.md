# RF08 — Criação de solicitação de recolhimento

## Endpoint

`POST /api/solicitacoes`

Cria uma solicitação de recolhimento vinculada a um morador, a um endereço cadastrado desse morador, a um ponto de coleta ativo e a um ou mais materiais aceitos pelo ponto.

## Corpo da requisição

```json
{
  "moradorId": 1,
  "enderecoId": 3,
  "pontoId": 2,
  "observacoes": "Preferência pelo período da manhã",
  "itens": [
    {
      "materialId": 4,
      "unidade": "kg",
      "quantidadeEstimada": 5.0
    }
  ]
}
```

`moradorId`, `enderecoId` e `pontoId` são obrigatórios e devem identificar registros existentes. `itens` deve conter pelo menos um item. Cada item exige `materialId`, `unidade` e `quantidadeEstimada` maior que zero.

## Validações realizadas

- O morador informado deve existir.
- O endereço informado deve existir e pertencer ao morador informado.
- O ponto de coleta deve existir e estar ativo.
- A solicitação deve conter pelo menos um item.
- Não é permitido repetir o mesmo material na lista de itens.
- Cada material deve estar ativo e cadastrado como aceito pelo ponto selecionado.
- A unidade informada deve corresponder à unidade de medida cadastrada para o material.
- Quando houver limite por solicitação configurado para o material naquele ponto, a quantidade estimada não poderá ultrapassá-lo.
- É aplicada a regra RN05 já existente no projeto: não criar outra solicitação enquanto houver uma solicitação aberta ou em andamento para o mesmo ponto.

## Persistência e histórico

A solicitação recebe um protocolo gerado pelo sistema e inicia com situação `SOLICITADA`. Os dados do endereço são copiados para a solicitação, preservando o endereço utilizado no momento da criação, conforme a RN04. Os itens e o primeiro registro de histórico são persistidos dentro da mesma transação.

## Resposta

Retorna HTTP `201 Created` com os dados da solicitação criada, incluindo protocolo, morador, ponto, cópia do endereço, situação, datas e itens.

## Erros esperados

- `400 Bad Request`: campos inválidos, endereço que não pertence ao morador, material não aceito, unidade incompatível, quantidade acima do limite ou material repetido.
- `404 Not Found`: morador, endereço ou ponto não encontrado.
- `409 Conflict`: ponto inativo ou existência de outra solicitação aberta/em andamento para o ponto.
